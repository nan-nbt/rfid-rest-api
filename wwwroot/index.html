Before you start

  • Get a client-credentials token from your IAM provider. The app validates its issuer, audience, expiry, and required role.
  • Connect requires a reachable reader IP and port. A client and a reader can each hold only one active connection.
  • Write expects a 24-character EPC. Production and warehouse actions write physical tags and update sample_barcode in PostgreSQL.
  • Disconnect when finished; sessions are held in memory by this server instance.
